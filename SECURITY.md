# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately, using the **Report a vulnerability** button on
this repository's
[Security tab](https://github.com/akuity/kargo/security/advisories/new). Do not
open a public issue or pull request for anything with security implications.

## Before you report

We read every report carefully, and each one takes real time to evaluate.
Please make sure yours is worth that time:

1. **Check that it isn't already known.** Look through the
   [published advisories](https://github.com/akuity/kargo/security/advisories)
   first. We may also be working privately on something you report. That's
   impossible for you to know, and if it happens, we'll tell you.
1. **Reproduce it.** Show the vulnerability working against the latest patch
   of a [supported](https://docs.kargo.io/release-support) Kargo release that
   you installed and run yourself. Please don't send a report you haven't
   verified. It moves the work of verifying it onto us, and that time comes
   out of fixing real problems.
1. **Test only against an installation you run.** Never test against a Kargo
   installation that someone else operates.
1. **Show what you observed.** Include the Kargo version, the steps you took,
   and the output or behavior that shows the impact.

If you use AI tools to find or write up a vulnerability, you are still
responsible for confirming that it's real before you report it.
